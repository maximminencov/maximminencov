## 🚀 Проекты

### 🏅 Анализ эффективности маркетинговых кампаний и клиентской базы

Итоговый аналитический проект по данным магазина спортивных товаров.

В проекте выполнены:

- очистка и подготовка данных;
- построение клиентской аналитической витрины;
- A/B-тест маркетинговой кампании;
- сегментация клиентов;
- построение модели склонности к покупке;
- подготовка аналитического отчёта и презентации.

**Результаты A/B-теста:**

- выручка на пользователя: **+18,61%**;
- количество покупок на пользователя: **+25%**.
