### 🛡 Анализ страховых данных и A/B-тестирование

End-to-end аналитический проект по страховым данным.

Проект включает полный аналитический цикл:

**Data Integration → Data Quality → Anomaly Detection → Customer Segmentation → A/B Testing → Business Recommendation**

В проекте выполнены:

- интеграция нескольких источников данных;
- построение страховой аналитической витрины;
- работа с внешним API курсов валют;
- очистка данных;
- выявление аномалий;
- иерархическая кластеризация;
- K-Means;
- выбор и интерпретация клиентских сегментов;
- A/B-тест новой схемы ценообразования;
- анализ конверсии, цены, выручки, убыточности и финансового результата;
- подготовка аналитического отчёта и презентации для менеджмента.

**Ключевой результат A/B-теста:**

- конверсия снизилась с **32,25% до 26,44%**;
- снижение составило **-5,82 п.п.** и является статистически значимым;
- средняя цена полиса выросла на **25,64%**;
- статистически подтверждённого улучшения финансового результата не обнаружено.

**Рекомендация:** сохранить текущую схему ценообразования и доработать новую модель перед повторным экспериментом.

👉 [Открыть проект](https://github.com/maximminencov/insurance-customer-analytics)
